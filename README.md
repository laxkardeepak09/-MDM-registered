# MDM All-In-One Register — MGGS AARNI (Android App & GitHub Pages)

यह प्रोजेक्ट आपकी `MDM.html` (एमडीएम ऑल-इन-वन रजिस्टर — महात्मा गांधी राजकीय विद्यालय आरनी) से तैयार किया गया है।

## शामिल फीचर्स (7 टैब):
1. **डैशबोर्ड (Overview & Quick Daily Entry)**
2. **दुग्ध वितरण एवं स्टॉक (मुख्यमंत्री बाल गोपाल योजना)**
3. **दैनिक पोषाहार (कक्षा 1-5)**
4. **दैनिक पोषाहार (कक्षा 6-8)**
5. **खाद्यान्न प्रपत्र (नोडलवार एकजाई)**
6. **राशि प्रपत्र (कुकिंग कन्वर्ज़न एवं कुक-कम-हेल्पर)**
7. **PM POSHAN MDCF (School Monthly Data Capture Format)**

## मोबाइल से GitHub पर APK बनाने का तरीका:
1. इस `MDM-All-In-One-Aarni-GitHub-App.zip` फाइल को अपने GitHub Repository में **Add file -> Upload files** से सीधा अपलोड कर दें।
2. **Actions** टैब में जाकर `.github/workflows/build.yml` फाइल में ऊपर दिया गया Workflow कोड पेस्ट करके Commit करें।
3. 2 मिनट में **Artifacts** सेक्शन में **MDM-All-In-One-MGGS-Aarni-APK** डाउनलोड के लिए तैयार हो जाएगा।
